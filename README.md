# Interactive-Covid-19-Dashboard---confirmed-cases-in-England-
Have a look at the number of Covid19 cases confirmed in England through this dashboard built in Jupyter notebook (with Python)

Dashboard features include:
- an interactive covid19 case graph for England
- a slider to display custom/relevant date range
- Explore the number of cases in the last 90 days (to the date you are reading this)
- download the latest available covid19 data from the UKHSA API
- load pandemic statistics from a local JSON dataset

click here to access the code via Binder: https://mybinder.org/v2/gh/ByteMe0001/Interactive-Covid-19-Dashboard---confirmed-cases-in-England-/main?urlpath=%2Fdoc%2Ftree%2FLive_Covid_DB.ipynb 

here is the UKHSA API link my dashboard utilises: [UKHSA COVID-19 daily cases API — England](https://api.ukhsa-dashboard.data.gov.uk/themes/infectious_disease/sub_themes/respiratory/topics/COVID-19/geography_types/Nation/geographies/England/metrics/COVID-19_cases_casesByDay?format=json&page_size=365&utm_source=chatgpt.com)
